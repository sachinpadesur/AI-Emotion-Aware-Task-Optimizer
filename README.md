# AI-Powered Employee Emotion-Aware Task Optimizer

An AI system that analyzes employee emotions in real time using text, facial expressions, and speech to recommend suitable tasks, detect stress, and improve workplace wellbeing.

## Features
- Real-time emotion detection
- AI-based task recommendation
- Stress & burnout alerts
- Historical mood tracking
- Team mood analytics
- Secure & anonymized data handling

## Run Project
pip install -r requirements.txt  
streamlit run app.py
